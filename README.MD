## Formatação de Texto
Mardown é fácil de formatar. Você pode usar:
- Negrito: `**bold**` **Negrito**
- Itálico `*italic*` *Itálico*  
- Riscado: `~~strikethrough~~` ~~Riscado~~

Também pode combinar:
- Negrito + Itálico: `***bold italic***` ***Negrito e itálico***

---

## Listas 
Para listas não ordenadas use -, * ou +:
```
* Item 1
- Item 2
+ Item 3
```
* Item 1
- Item 2
+ Item 3

Para listas ordenadas, use os números de referência:
```
1. Item 1
2. Item 2
3. Item 3
```
1. Item 1
2. Item 2
3. Item 3

## Citações
Para citações a sintaxe funciona da seguinte forma:

```
> Cada cachorro que lamba sua caceta.
>
>-Nóbrega, Victor
```

Citações podem conter outros elementos de mardown. Exemplo:
>**Dica** Use `Cmd + shift + Z` para entrar no modo Zen e escrever sem distrações.

---

Código
- Para blocos de código utilize a sintaxe ``` antes de iniciar e depois que encerrar o código:
```
Código
```
- Também é possível usar apenas o código entre os sinais ``. Exemplo:
`Código`
