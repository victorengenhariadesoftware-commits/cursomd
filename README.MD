## Formatação de Texto
Mardown é fácil de formatar. Você pode usar:
- Negrito: ```**bold**```
- Itálico ```*italic*```
- Riscado: ```~~strikethrough~~```

Também pode combinar:
- Negrito + Itálico: ```***bold italic***```
- Código da mesma linha: `inline code` (colocar entre ``)

---

## Listas 
Para listas não ordenadas use -, * ou +:
```
* Item 1
- Item 2
+ Item 3
```

Para listas ordenadas, use os números de referência:
```
1. Item 1
2. Item 2
3. Item 3
```

---

## Para trabalhar com listas aninhadas, você pode usar - e 3 espaços + -:
```
- Integrações cloud
   - Repositórios github
   - Pastas do dropbox
   - Arquivos do google drive
- Local Features
   - Imagem de pasta
   - Auto salvamento para inventário
```
