## Formatação de Texto
Mardown é fácil de formatar. Você pode usar:
- Negrito: ```**bold**```
- Itálico ```*italic*```
- Riscado: ```~~strikethrough~~```

Também pode combinar:
- Negrito + Itálico: ```***bold italic***```
- Código da mesma linha: `inline code` (colocar entre ``)

## Listas 
Para listas não ordenadas use -, * ou +:
```
* Item 1
- Item 2
+ Item 3
```
